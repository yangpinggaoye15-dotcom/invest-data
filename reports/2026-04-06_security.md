## 外部脅威情報（Geminiより）

本システムに関連するリスクを以下に抽出・整理する。

### 🔴 高優先度

**① GitHub Actions「prt-scan」攻撃キャンペーン**
- [事実] 2026年4月2日、`pull_request_target` ワークフロートリガーを悪用する組織的キャンペーンが確認された。500件以上の悪意あるPRが送信され、少なくとも2つのnpmパッケージが侵害された。
- [AI分析] 本プロジェクトがGitHub Actionsでサーバーレス関数のデプロイやテストを行っている場合、外部コントリビューターからのPRにより `ANTHROPIC_API_KEY` / `GEMINI_API` が漏洩するリスクがある。`pull_request_target` の使用有無を即時確認すべきである。

**② Anthropic Claude Codeソースコード漏洩（2026-03-31）**
- [事実] AnthropicがClaude Codeのソースコードをnpmパッケージのソースマップ経由で誤公開し、数時間以内にGitHubで数万回フォークされた。
- [事実] CVE-2026-21852（Claude Codeのプロジェクトロードフローにおける情報漏洩。悪意あるリポジトリがAnthropic APIキーを外部送信できる）が存在し、Claude Code 2.0.65以降で修正済み。
- [AI分析] 本プロジェクトがClaude Codeを開発ツールとして使用している場合、バージョン 2.0.65未満では信頼できないリポジトリをclone・openするだけでAPIキーが漏洩する可能性がある。即時バージョン確認を要する。
- [AI分析] 漏洩したClaude Codeを装った悪意あるリポジトリ・npmパッケージが流通しているため、依存パッケージの出所確認（`npm audit` + lockfile検証）を推奨する。

### 🟡 中優先度

**③ Vercel / Next.js 複数CVE（2026年3月公開）**
- [事実] CVE-2026-27980：Next.js 10.0.0〜16.1.7未満の画像最適化機能のディスクキャッシュ無制限によるDoS。
- [事実] CVE-2026-23864：React Server ComponentsへのDoS（Next.js 13.x〜16.x対象）。
- [事実] CVE-2026-29057 / CVE-2026-27978 / CVE-2026-27979 / CVE-2026-27977：Next.jsにおけるWebSocketクロスサイト保護バイパス、Server Action CSRF検証のnullオリジン処理誤り等。
- [AI分析] Vercelプラットフォーム上でホストされているため、CVE-2026-23864についてはVercelのWAFが一部自動保護しているが、最新パッチへのアップグレードで根本対処が必要。CSRF検証バイパス系CVEは `api/claude.js` / `api/gemini.js` のServer Actionsに直接影響しうる。

**④ Google Cloud APIキー漏洩リスク**
- [事実] 2026年2月27日、公開されたGoogle APIキーがGemini AIの認証にも流用可能であることが判明し、Truffle SecurityがGitHub上で2,863件の公開Google APIキーを確認した。
- [AI分析] `GEMINI_API` キーがGitHub SecretsおよびVercel環境変数で正しく管理されていれば直接リスクは低い。ただし万一キーがログ・エラーメッセージ経由で露出した場合、Gemini APIへの不正アクセスのみならず、他Google Cloudサービスへのアクセス拡大リスクがある点に留意が必要。

**⑤ Python依存パッケージ脆弱性**
- [事実] CVE-2026-30922（pyasn1 ≤0.6.2のDoS）、CVE-2025-12781（base64モジュールb64decode()のデータ整合性問題）、CVE-2025-0938（URLパーサーの角括弧許可問題）が2026年3月までに公開されている。
- [AI分析] 本プロジェクトのバックエンドまたはCI環境でPythonを使用している場合、依存パッケージのバージョン確認が必要。特にAPIキーを処理するパイプラインでbase64デコードを行っている場合はCVE-2025-12781の影響を精査すること。

## 要対応事項

### 🔴 即時対応（本日中〜48時間以内）

1. **[AI分析] GitHub Actionsワークフロー精査**
   `pull_request_target` トリガーを使用しているワークフローを全件確認し、外部PRからのシークレットアクセスを遮断する設定（`if: github.event.pull_request.head.repo.full_name == github.repository` 等）が実装されているか検証すること。

2. **[AI分析] Claude Codeバージョン確認**
   開発環境で使用中のClaude Codeが v2.0.65以上であることを確認すること。未満の場合は即時アップデートし、CVE-2026-21852の影響を排除すること。

3. **[AI分析] 依存パッケージのサプライチェーン確認**
   `npm audit` および `pip audit` を実行し、Claude Codeリーク便乗の悪意あるパッケージが混入していないことを確認すること。lockfileのハッシュを検証すること。

### 🟡 近日対応（1週間以内）

4. **[AI分析] Next.jsバージョンアップグレード確認**
   CVE-2026-27980・CVE-2026-29057等の影響バージョン（Next.js 16.1.7未満）に該当するか確認し、該当する場合はパッチ適用またはバージョンアップを実施すること。

5. **[AI分析] GEMINI_API / ANTHROPIC_API_KEY ローテーション検討**
   Claude Codeリーク・Google APIキー漏洩インシデントを踏まえ、予防的措置として両APIキーのローテーション（再発行・旧キー無効化）を検討すること。特にAPIキーがログに出力されていないか確認すること。

## 推奨事項

1. **[AI分析] GitHub Actionsのシークレット保護強化**
   `pull_request_target` を使用する場合は必ず環境（`environment` protection rules）を設定し、外部コントリビューターのPRに対してシークレットが自動展開されない設計とすること。また、ワークフローに `permissions: read-all` を明示的に設定し、最小権限原則を適用することを推奨する。

2. **[AI分析] Vercel WAF設定の見直し**
   CVE-2026-23864に対するVercel WAFの自動保護が有効であることをVercelダッシュボードで確認すること。加えて、`api/claude.js` / `api/gemini.js` へのリクエストレートリミットを設定し、DoS耐性を高めること。

3. **[AI分析] APIキーアクセスログの定期監視**
   Anthropic APIおよびGemini APIの利用状況ダッシュボードを週次で確認し、想定外のAPI呼び出し急増（キー漏洩の兆候）を早期検知する体制を整えること。

4. **[AI分析] 開発環境でのAIエージェント使用ポリシー策定**
   Google Cloudのレポートが指摘する「シャドーエージェント」問題を踏まえ、開発チーム内でClaude Code等のAIコーディングエージェントを使用できるリポジトリ・環境を明文化し、未承認AIエージェントの使用を制限するポリシーを策定することを推奨する。

5. **[AI分析] SNS型投資詐欺に関する社内周知**
   [事実] 2026年4月6日時点で国内複数警察署がSNS型投資詐欺の注意喚起を発出している。[AI分析] 本システムのユーザー向けに、SNS経由の不審な投資勧誘への警戒を促すUI通知またはヘルプページの整備を検討すること。
