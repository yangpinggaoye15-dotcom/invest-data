## 外部脅威情報（Geminiより）

本システムのスタック構成（Python/GitHub Actions/Vercel/Anthropic API/Gemini API）に直接関連するリスクを以下に抽出する。

### 🔴 高優先度リスク

**① Trivyサプライチェーン攻撃によるGitHub Actionsクレデンシャル窃取**
[事実] 2026年3月、「TeamPCP」によりTrivyのGitHub Actionsワークフローが改ざんされ、情報窃取マルウェアが実行された。CiscoのソースコードもこのルートでのCred窃取が原因とされている。
[AI分析] 本プロジェクトがTrivyをCI/CDで利用している場合、直接的な被害を受けた可能性がある。利用の有無を即時確認すべき最優先事項と判断する。GitHub SecretsにAPIキー（`ANTHROPIC_API_KEY`, `GEMINI_API`）が格納されており、Actions経由での窃取リスクが現実的脅威として存在する。

**② Next.js / Vercel 複数CVE**
[事実] CVE-2025-48985（CSRF検証の`origin: null`バイパス）、CVE-2026-23864（React Server Components DoS）、CVE-2026-29057 他複数のCVEが報告されている。
[AI分析] 本システムがVercel+Next.jsを採用している場合、特にServer Actionを使用している `api/claude.js`, `api/gemini.js` がCSRFバイパスの影響を受ける可能性がある。未認証リクエストによるAI API不正利用（コスト爆発攻撃）につながるリスクを評価すべきと判断する。

**③ Claude Code脆弱性（CVE-2025-59536 / CVE-2026-21852）**
[事実] Anthropic製Claude Codeに、悪意あるリポジトリ設定ファイルを介したリモートコード実行およびAPIキー窃取を可能にする脆弱性が存在していた（修正済み）。
[AI分析] 開発チームがClaude Codeを利用してコード生成を行っている場合、過去の開発フェーズで生成されたコードにAPIキーがハードコーディングされていないか、改めてgit履歴のスキャンを実施すべきと判断する。

**④ Pythonライブラリの複数CVE**
[事実] `requests`ライブラリ（CVE-2026-25645）、`pkgutil`（CVE-2026-3479 パストラバーサル）、`http.cookies.Morsel`（CVE-2026-3644）、Python-Pyasn1 DoS（CVE-2026-30922）等が報告されている。

## 要対応事項

### 即時対応（24時間以内）

[AI分析] 以下の項目は緊急度が高く、即時確認・対応を要すると判断する。

1. **TrivyのCI/CD利用確認**
   [AI分析] `.github/workflows/` 内のワークフローファイルを確認し、Trivyアクション（`aquasecurity/trivy-action`等）を使用している場合、利用バージョンとコミットハッシュを確認。サプライチェーン汚染の影響有無を評価し、GitHub SecretsのAPIキー（`ANTHROPIC_API_KEY`, `GEMINI_API`）をローテーション（再発行）することを推奨する。

2. **git履歴のシークレットスキャン実施**
   [事実] `6ff78f2 screening` コミットの具体的な変更内容が未確認。[AI分析] `git-secrets`、`trufflehog`、`gitleaks` 等のツールを使用して全コミット履歴のフルスキャンを実施し、`sk-`, `AIza`, `Bearer`, `ANTHROPIC`, `GEMINI` パターンの混入を確認すること。

### 短期対応（1週間以内）

3. **Next.js / Vercelバージョン確認とパッチ適用**
   [事実] CVE-2025-48985（CSRF `origin: null` バイパス）はNext.js 16.0.1〜16.1.7に影響。[AI分析] 使用中のNext.jsバージョンを確認し、CVE対象範囲内であれば即時アップグレードを実施すること。

4. **GitHub Actionsのハッシュピン留め確認**
   [AI分析] 全ワークフローファイルにおいてサードパーティActionの参照がタグ（`@v3`等）ではなくコミットハッシュ（`@sha256:...`）でピン留めされているかを確認・修正すること。

5. **Vercel Serverless関数のコードレビュー**
   [AI分析] `api/claude.js` および `api/gemini.js` の実装において、レート制限・認証チェック・入力バリデーション・エラーハンドリングが適切に実装されているかをレビューすること。特に未認証の外部リクエストによるAI API不正呼び出し（コスト爆発）リスクを評価すること。
