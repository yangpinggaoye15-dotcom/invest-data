## 要対応事項

[AI分析] 以下を優先度順に対応することを推奨する。

### 🔴 優先度：高（今週中）

1. **Next.jsバージョン確認・アップデート**
   [AI分析] 現在使用中のNext.jsバージョンを確認し、16.1.7未満または15.5.13以下の場合は速やかにアップデートを実施すること。CVE-2026-27977/27978（CSRFバイパス）およびCVE-2026-29057が対象。

2. **依存パッケージのサプライチェーン汚染確認**
   [AI分析] `litellm`（PyPI）および `axios`（npm）の使用バージョンを確認し、問題バージョン（litellm 1.82.7/1.82.8）を使用していないか検証すること。該当する場合はシークレットを即時ローテーションし、Vercel・GitHub Secretsの全キーを再発行する。

### 🟡 優先度：中（今月中）

3. **GitHub Actionsワークフローの依存アクション固定**
   [AI分析] ワークフロー内で参照している外部Actionsを、タグやブランチ参照ではなくコミットSHA（例：`uses: actions/checkout@a5ac7e51b41094c92402da3b24376905380afc29`）でピン留めすること。Trivyをはじめとするセキュリティスキャンアクションが改ざんされていないかを確認する。

4. **シークレットの定期ローテーション実施**
   [事実] 業界全体でAPIキー流出インシデントが相次いでいる（2026年3月〜4月）。[AI分析] 予防的措置として、`ANTHROPIC_API_KEY` および `GEMINI_API` を含む全シークレットのローテーションを今月中に実施することを推奨する。

5. **Python依存ライブラリの更新確認**
   [AI分析] `pyasn1` を0.6.3以上へ、`wheel` を0.46.1超へ更新すること。CVE-2026-3644への対応としてPythonの `http.cookies` モジュール使用箇所のバージョンを確認する。

## 推奨事項

[AI分析] 以下は中長期的な改善として推奨する。

1. **依存パッケージの自動脆弱性スキャン導入**
   [AI分析] GitHub DependabotまたはSnykをGitHub Actionsに組み込み、新規CVE検出時に自動アラートを受け取る体制を構築することを推奨する。サプライチェーン攻撃対応の初動を短縮できる。

3. **Vercel Server ActionsのCSRF対策確認**
   [AI分析] CVE-2026-27977/27978のCSRFバイパス脆弱性に対応するため、Server Actions使用箇所に独自のCSRFトークン検証レイヤーが実装されているかを確認し、フレームワーク組み込みの保護のみに依存しない設計を検討すること。
