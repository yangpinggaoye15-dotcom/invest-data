## 外部脅威情報（Geminiより）

### 🔴 本システムへの関連度：高

**① Vercel / Next.js 脆弱性群**
- [事実] 2026年3月20日更新分として、Next.jsに複数の脆弱性（CVE-2026-29057、CVE-2026-27978、CVE-2026-27979、CVE-2026-27977、CVE-2026-27980）が報告されている。
- [事実] React Server Componentsに複数のDoS脆弱性（CVE-2026-23864）が発見されており、Vercel WAFによる保護はあるがパッチ適用が推奨されている。
- [AI分析] 本システムはVercelをデプロイ基盤として使用しており、これらの脆弱性は直接的な影響範囲に含まれる可能性が高い。現在使用しているNext.js / Reactのバージョンを早急に確認し、修正バージョンへのアップグレード可否を検討する必要がある。

**② GitHub Actions サプライチェーンリスク**
- [事実] 2026年3月、TrivyのGitHub Actions環境の設定ミスを悪用したサプライチェーン攻撃が発生し、SSHキー・クラウドアクセスキー・Kubernetesトークン等が窃取された。
- [事実] Axiosを標的とした「遅延型」サプライチェーン攻撃（2026年3月）により、CI/CDパイプライン経由のAPIキー漏洩リスクが報告されている。
- [AI分析] 本システムのCI/CDパイプラインで使用しているnpmパッケージ（特にAxios等の通信ライブラリ）が汚染されていた場合、`ANTHROPIC_API_KEY` / `GEMINI_API` がCI実行環境で漏洩するリスクがある。直近のAxios使用バージョンおよびロックファイル（`package-lock.json`）の整合性確認を推奨する。

**③ Anthropic / Google AI API 関連リスク**
- [事実] 2026年3月31日、Anthropicの「Claude Code」npmパッケージにソースマップファイルが誤同梱されソースコードが一時公開された。Anthropicは顧客APIキー・会話履歴の漏洩はないと説明している。
- [事実] IPAの「情報セキュリティ10大脅威 2026」に「AIの利用をめぐるサイバーリスク」が初めて選出された。
- [AI分析] 本システムはAnthropicおよびGoogle AIのAPIを中核機能として使用しており、これらAPIプロバイダー側のセキュリティインシデントはサービス継続性・データ保護の両面でリスク要因となる。プロバイダーからの公式セキュリティアドバイザリを継続的にモニタリングする体制が必要である。
