## 外部脅威情報（Geminiより）

### 🔴 本システムに直接関連する高リスク項目

**① Next.js / Vercel 関連脆弱性**

- [事実] **CVE-2026-29057**: Next.js バージョン 9.5.0 以降・15.5.13 および 16.1.7 未満において、`Transfer-Encoding: chunked` を利用した `DELETE`/`OPTIONS` リクエストによる **HTTPリクエストスマグリング脆弱性**が報告されている。外部バックエンドへのプロキシ書き換えを行う構成が対象。
- [AI分析] 本システムはVercel上でapi/claude.js・api/gemini.jsをサーバーレスプロキシとして運用しており、Next.jsのバージョンが上記範囲内に該当する場合、APIエンドポイントへのリクエストスマグリング攻撃を受けるリスクがある。**Next.jsのバージョンを15.5.13以降または16.1.7以降へ早急にアップデートすることを推奨する。**
- [事実] **CVE-2026-23864**: Next.js App Router Server Functionエンドポイントへの特細工リクエストにより、**過剰なCPU使用またはOOMを引き起こすDoS脆弱性**が報告されている。
- [AI分析] 深層分析機能（今回追加の4機能）がApp Routerのサーバー関数を使用している場合、DoS攻撃の標的となりうる。追加機能のルーティング構成を確認し、入力値のサイズ・形式バリデーションを強化すること。

**② Anthropic / Google AI API キー管理リスク**

- [事実] 2025年4月に個人開発者のAnthropic APIキーが窃取され、短時間で大量のClaude 3.7 Sonnetが不正利用された事例が報告されている。GitHubリポジトリからの漏洩は確認されず、スパイウェア関与が疑われている。
- [事実] OWASPの2025年 LLM Top 10において、**API Token漏洩が最大の脅威ベクター**とされている。
- [AI分析] 本システムのAPIキーはGitHub Secrets + Vercel Env Varsで適切に管理されており、現時点でリポジトリ経由の漏洩リスクは低い。ただし開発者端末のマルウェア感染によるキー窃取のリスクは残存しており、定期的なキーローテーションを推奨する。
- [事実] **Claude Codeの記憶改ざん手法**（Cisco報告、2026年4月1日）: MEMORY.md等の記憶ファイルを書き換えることで、セッションをまたいで不正指示を継続出力させる手法が確認された。AIがAPIキーをソースコードに直接埋め込むよう推奨する事例が確認されている。
- [AI分析] 本システムがAIコーディング支援ツール（Claude Code等）を開発フローで使用している場合、生成コードへのAPIキーハードコードが混入するリスクがある。AIが生成したコードはマージ前に必ずAPIキーパターンのスキャン（`sk-`, `AIza`, `Bearer`等）を実施すること。

**③ GitHub Actions 関連脆弱性**

- [事実] **CVE-2026-1699**: `pull_request_target` トリガーを使用したGitHub Actionsワークフローで、任意ユーザーによる任意コード実行が可能な脆弱性が報告されている。
- [事実] **CVE-2026-27701**: PRタイトルを通じたJavaScriptインジェクション脆弱性が報告されている。
- [AI分析] 現在のワークフローが `pull_request_target` を使用していないかを確認し、使用している場合は `pull_request` トリガーへの変更または外部コードのチェックアウト時の権限分離を実施すること。

**④ Python 依存ライブラリ関連脆弱性**

- [事実] **CVE-2026-25645**: Requests ライブラリ バージョン 2.33.0 未満に zipアーカイブ展開時の予測可能ファイル名による脆弱性が報告されている。
- [事実] **CVE-2026-3479**: `pkgutil.get_data()` のパストラバーサル脆弱性が報告されている。
- [事実] **CVE-2026-30922**: `pyasn1` バージョン 0.6.3 未満にDoS脆弱性が報告されている。
- [AI分析] バックエンド処理にPythonを使用している場合、上記ライブラリのバージョン確認とアップデートが必要。特にRequestsライブラリは広く使用されており、優先的に対応すること。

**⑤ サプライチェーンリスク**

- [事実] npmパッケージ「Axios」が北朝鮮背景グループにより侵害され、インストールから15秒以内にRATを配布する事案が報告されている。
- [AI分析] 今回追加された「4つの深層分析機能」において新規npmパッケージが追加されていないかを確認すること。package.jsonおよびpackage-lock.jsonの差分レビューを実施し、不審なパッケージの混入がないかを検証する必要がある。
