## 外部脅威情報（Geminiより）

本システム（Python + GitHub Actions + Vercel / Next.js + Anthropic & Google AI API）に関連する脅威を以下に整理します。

### 🔴 高優先度

| # | 脅威・CVE | 本システムへの関連性 |
|---|-----------|----------------------|
| 1 | **CVE-2026-27980 / CVE-2026-23864**（Vercel Next.js DoS） | Vercelデプロイの画像最適化・React Server Components に対するDoS攻撃が可能。外部公開エンドポイントが存在する場合、サービス停止リスクあり。 |
| 2 | **CVE-2025-59536 / CVE-2026-21852**（Claude Code RCE・APIキー窃取） | 開発者がClaude Codeを使用している場合、悪意あるリポジトリをクローンするだけでAPIキー（`ANTHROPIC_API_KEY`）が窃取される可能性。開発環境を狙った攻撃ベクタ。 |
| 3 | **AIを活用した認証情報攻撃**（33億件流出情報の自動照合） | 証券・投資ドメインのシステムは標的になりやすい。管理者アカウントへのクレデンシャルスタッフィング攻撃が高速化・自動化されている。 |

### 🟡 中優先度

| # | 脅威・CVE | 本システムへの関連性 |
|---|-----------|----------------------|
| 4 | **CVE-2026-1699 / CVE-2026-27701**（GitHub Actions RCE） | `pull_request_target` / JavaScriptインジェクションによるCI/CDパイプライン乗っ取り。本システムのワークフロー設計が安全であることは確認済みだが、依存するサードパーティActionのバージョン固定を要確認。 |
| 5 | **CVE-2026-0994 / CVE-2026-30922**（Python DoS） | バックエンドでpyasn1・protobufを使用している場合、バージョン未更新によりDoS攻撃を受ける可能性。依存ライブラリの棚卸しが必要。 |
| 6 | **CVE-2026-27977〜27979 / CVE-2026-29057**（Next.js CSRF・WebSocket） | `Origin: null` バイパスによるCSRF検証回避。Server ActionやWebSocketを利用している機能で影響範囲を確認する必要あり。 |
| 7 | **APIキー窃取（脆弱なOSSツール悪用）** | 開発環境で使用するAIツール経由でAPIキーが闇市場に流出するリスク。`ANTHROPIC_API_KEY` / `GEMINI_API` のローテーション体制を整備すべき。 |

### 🟢 参考情報

- SNS型投資詐欺が2025年に被害総額3,000億円超を記録。本システムのユーザー向けに「公式以外の投資誘導に注意」等の啓発コンテンツの追加を検討。
- Googleの脅威インテリジェンス（GTIG）がAI悪用の偵察・ソーシャルエンジニアリングの高度化を報告。開発チームへのセキュリティ意識向上トレーニングを推奨。

## 要対応事項

### ⚡ 即時対応（今週中）

1. **Vercel / Next.js をパッチ済みバージョンへ更新**
   - CVE-2026-27980・CVE-2026-23864・CVE-2026-27977〜29057 の修正バージョンを確認し、`package.json` を更新、ステージング環境でリグレッションテスト後に本番反映。

2. **Claude Code 利用者への注意喚起**
   - 開発チーム全員に CVE-2025-59536 / CVE-2026-21852 を周知。信頼できないリポジトリの安易なクローン・オープンを禁止。Claude Code を最新バージョンに更新。

3. **`ANTHROPIC_API_KEY` / `GEMINI_API` の即時ローテーション検討**
   - 上記Claude Codeの脆弱性が開発環境で悪用された可能性を排除するため、予防的ローテーションを実施し、Vercel Env Vars・GitHub Secretsへ再登録。

### 📅 今月中（2026年4月末まで）

4. **Python依存ライブラリの棚卸しと更新**
   - `pyasn1` を `0.6.3` 以上へ更新（CVE-2026-30922 対策）。`protobuf` ライブラリのバージョン確認（CVE-2026-0994 対策）。

5. **GitHub Actions の依存Actionをコミットハッシュで固定**
   - `uses: actions/checkout@v4` 等をコミットSHA形式（`uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683`）に変更し、サプライチェーン攻撃を抑止。

6. **MFA（多要素認証）の全管理者アカウントへの強制適用確認**
   - GitHub・Vercel・AI APIコンソール（Anthropic / Google Cloud）の管理者アカウントすべてでMFAが有効であることを確認・記録。

## 推奨事項

### 短期（1〜2ヶ月）

- **Dependabot / Renovate Bot の有効化**: Next.js・Pythonライブラリの脆弱性パッチを自動PRで検知する仕組みを整備する。
- **CSP（Content Security Policy）ヘッダーの強化**: CDN禁止ルールをコード・ポリシー両面で担保するため、`script-src 'self'` を明示的に設定し、外部スクリプト混入を技術的に防止する。
- **APIキーのスコープ最小化**: Anthropic・Google AI の APIキーを機能別に分割し、権限を最小限に絞る（Principle of Least Privilege）。

### 中期（3〜6ヶ月）

- **SAST（静的解析）をCI/CDに統合**: `truffleHog` / `gitleaks` をGitHub Actionsパイプラインに組み込み、シークレット混入を自動検知する体制を構築。
- **インシデントレスポンス手順書の整備**: APIキー漏洩・不正アクセス検知時のエスカレーションフロー、ローテーション手順、ユーザー通知基準を文書化する。
- **ユーザー向けセキュリティ啓発**: 本システムが扱う「出来高分析」「大量保有報告書」等の投資情報を悪用したSNS型投資詐欺が発生する可能性を踏まえ、公式チャネルの明示とフィッシング注意喚起をUI上に追加する。

### 長期（6ヶ月以上）

- **ゼロトラストアーキテクチャへの移行検討**: 委託先・サードパーティツールを含むサプライチェーン全体の可視化と継続的な信頼検証（継続的認証）の導入を検討。
- **AIセキュリティポリシーの策定**: 開発チームがAIコーディングツールを使用する際のセキュリティガイドラインを策定し、承認済みツールリストを管理する。
