## 外部脅威情報（Geminiより）

### 🔴 本システムへの直接的関連リスク

**① Next.js / React Server Components 脆弱性**
[事実] CVE-2026-23864として、React 19.0.x〜19.2.x および Next.js 13.x〜16.x において、細工されたHTTPリクエストによりサーバークラッシュ・OOM・高CPU消費が引き起こされる DoS 脆弱性が確認されている。
[AI分析] Vercel上でホストされる本プロジェクトのServerless Functionsが当該バージョンを使用している場合、`api/claude.js` および `api/gemini.js` エンドポイントが標的となりうる。Vercel WAFは部分的な緩和策に留まるため、パッチ済みバージョンへの即時アップグレードが最優先事項となる。

**② Axiosサプライチェーン侵害（npmパッケージ）**
[事実] 2026年4月1日、週1億回以上ダウンロードされるnpmパッケージ「Axios」が北朝鮮系攻撃グループにより侵害され、クロスプラットフォームRATが配布されたことが報告されている。
[AI分析] 本プロジェクトの `package.json` においてAxiosを依存パッケージとして使用している場合、CI/CD環境・開発者端末・Vercelビルド環境へのマルウェア混入リスクがある。`npm audit` の即時実行と `package-lock.json` のハッシュ検証を強く推奨する。

**③ GitHub Actions サプライチェーン攻撃リスク**
[事実] 2026年3月、TrivyリポジトリへのGitHub Actions設定ミスを悪用した攻撃により、CI/CDパイプラインへの悪意あるコード混入とクレデンシャル窃取が発生した。
[AI分析] 本プロジェクトのGitHub Actionsワークフローにおいて、使用しているサードパーティActionが固定SHAでピン留めされていない場合、同様の攻撃ベクターが成立する。全Actionの `@sha256:xxxx` 形式へのピン留めを推奨する。

**④ Claude Code ソースコード流出（Anthropic API利用者への影響評価）**
[事実] 2026年3月31日、`@anthropic-ai/claude-code` v2.1.88 のnpmパッケージに内部デバッグ用ソースマップが誤混入し、約51万行のソースコードが公開された。Anthropicは顧客データ・認証情報の流出はないと発表している。
[AI分析] 本プロジェクトが `ANTHROPIC_API_KEY` を使用している点において、APIキー自体の流出は確認されていないが、流出したコードから内部APIの仕様・エンドポイント構造が推測される可能性がある。APIキーのローテーションを予防的措置として推奨する。

**⑤ Gemini API 課金制限の運用影響**
[事実] 2026年4月1日よりGemini APIの課金キャップが正式施行され、月間上限到達時にAPIリクエストが停止される。また `gemini-2.0-flash-lite` は2026年6月1日にシャットダウン予定。
[AI分析] `api/gemini.js` において使用モデルの確認が必要。`gemini-2.0-flash-lite` を使用している場合は `gemini-2.5-flash-lite` への移行計画を即時策定する必要がある。また課金上限による予期せぬサービス停止がセキュリティ上の可用性リスクとなりうる。

## 要対応事項

### 🔴 緊急（72時間以内）

1. **[AI分析] Next.js バージョン確認とパッチ適用**
   - `package.json` / `package-lock.json` にて使用中のNext.js・Reactバージョンを確認し、CVE-2026-23864・CVE-2026-29057の影響範囲を特定する。
   - 影響バージョンに該当する場合は修正済みバージョンへ即時アップグレードしデプロイする。

2. **[AI分析] Axios依存の確認と `npm audit` 実行**
   - [事実] 2026年4月1日のAxios侵害報告を受け、本プロジェクトの全依存パッケージを検査する。
   - `npm audit --audit-level=high` を実行し、結果をセキュリティチームへ報告する。

### 🟡 短期（1週間以内）

3. **[AI分析] ANTHROPIC_API_KEY のローテーション**
   - Claude Codeソースコード流出事案（[事実] 2026年3月31日発生）を受けた予防的措置として、Anthropic Consoleにてキーを再発行し、GitHub Secrets・Vercel Env Varsを更新する。

4. **[AI分析] GitHub Actions ワークフローのセキュリティ強化**
   - 全サードパーティActionを `@sha256:` ハッシュ形式でピン留め。
   - `pull_request_target` トリガーの使用有無を確認し、使用している場合は信頼できないコードを実行しない構成に修正する。
   - シークレットのスコープを必要最小限のジョブ・ステップに制限する。

5. **[AI分析] Gemini使用モデルの確認と移行計画策定**
   - `api/gemini.js` にて `gemini-2.0-flash-lite` を使用している場合、[事実] 2026年6月1日シャットダウンまでに `gemini-2.5-flash-lite` への移行を完了させる。

6. **[AI分析] `screening` コミット（f77ee4e）の詳細レビュー**
   - コミットメッセージのみでは変更内容が不明なため、`git diff f77ee4e~1 f77ee4e` によるフルdiffレビューを実施し、外部URLの追加・設定変更・機密情報の混入がないことを確認する。
