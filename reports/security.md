## 外部脅威情報（Geminiより）

### 🔴 本システムへの関連度：高

**① LiteLLMサプライチェーン攻撃（PyPI経由マルウェア配布）**
- [事実] 攻撃グループ「TeamPCP」がLiteLLMのPyPIメンテナーアカウントを乗っ取り、不正バージョン（1.82.7、1.82.8）を配布。SSHキー・APIキー・クラウドアクセスキーを窃取するマルウェアが含まれていた。
- [AI分析] 本システムはAnthropicおよびGoogle Gemini APIを利用しており、関連Pythonライブラリ（`litellm` 等）を依存関係に持つ場合、当該不正バージョンを取り込むリスクがある。`pip list` / `requirements.txt` / `package-lock.json` の即時確認を強く推奨する。

**② GitHub Actions CVE-2026-1699（CVSS 10.0 Critical）**
- [事実] `pull_request_target` トリガーを使用するワークフローで、信頼できない外部PRのコードが実行され、リポジトリシークレットおよび `GITHUB_TOKEN` が窃取可能となる重大脆弱性。
- [AI分析] 本システムの GitHub Actions ワークフローが `pull_request_target` トリガーを使用している場合、`ANTHROPIC_API_KEY` / `GEMINI_API` の漏洩につながる最高リスク。ワークフローファイルの即時レビューを推奨する。

- [事実] Vercel Next.js において、DoS（ディスクキャッシュ無制限増加）、開発サーバーWebSocketバイパス（CVSS 5.4）、Server Action CSRFバイパス（CVSS 4.3）、リクエスト密輸（CVSS 6.5）の脆弱性が報告された。
- [AI分析] 本システムがVercelにデプロイされNext.jsを利用している場合、これらは直接影響する。特にリクエスト密輸（CVE-2026-29057）はAPIプロキシ経路（`api/claude.js`, `api/gemini.js`）において認証・認可バイパスのリスクとなりうる。

**④ Langflow CVE-2026-33017（CVSS 9.3 / リモートコード実行）**
- [事実] AIプラットフォームLangflowに認証不要のコードインジェクション脆弱性。開示から20時間以内に攻撃が観測された。バージョン1.9.0.dev8で修正済み。
- [AI分析] 本システムがAIワークフロー基盤としてLangflowを採用していない場合は影響なし。ただし、社内他システムとの連携がある場合は横断的確認が必要。

**⑤ Python `requests` ライブラリ CVE-2026-25645**
- [事実] `requests.utils.extract_zipped_paths()` が予測可能なファイル名で一時ファイルを生成し、悪意あるファイルを読み込む可能性。バージョン2.33.0で修正済み。
- [AI分析] バックエンド（Vercel Serverless関数）でPythonの `requests` ライブラリを使用している場合、バージョン確認が必要。
