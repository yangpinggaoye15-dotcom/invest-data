## 外部脅威情報（Geminiより）

### 本システムに関連するリスクの抽出

**【高関連度】Next.js / Vercel 脆弱性群**

- [事実] CVE-2026-27977: Next.js 開発モードにおいて `Origin: null` によるWebSocket CSRF保護バイパスが確認されている（バージョン16.1.7で修正済）。
- [事実] CVE-2026-27978: Server Action の CSRF 検証において `origin: null` がバイパスされる脆弱性（バージョン16.1.7で修正済）。
- [事実] CVE-2026-27979: `next-resume` ヘッダーを含む特大POSTペイロードによるDoS（バージョン16.1.7で修正済）。
- [事実] CVE-2026-29057: DELETE/OPTIONS リクエストを用いたHTTPリクエストスマグリング（15.5.13以前および16.1.7未満に影響）。
- [AI分析] 本システムが `api/claude.js`, `api/gemini.js` でサーバーアクションまたはAPIルートを使用している場合、CSRF バイパスおよびリクエストスマグリング脆弱性が直接的な攻撃ベクタとなりうる。**Next.js バージョンの即時確認とアップグレードを最優先とする。**

**【高関連度】Python 脆弱性**

- [事実] CVE-2026-4519: Python 3.15.0 未満において任意コード実行の可能性（CVSSスコア 7.1）。
- [事実] CVE-2026-25645: Requests ライブラリの `extract_zipped_paths()` 関数における予測可能ファイル名によるローカル攻撃リスク（Requests 2.33.0 で修正済）。
- [AI分析] 本システムのバックエンドまたはスクリプト環境で Python および Requests ライブラリを使用している場合、バージョン確認とパッチ適用が必要。

**【高関連度】Anthropic Claude Code ソースコード漏洩**

- [事実] 2026年3月31日、Anthropicは `@anthropic-ai/claude-code` バージョン2.1.88 のnpmパッケージに約513,000行のTypeScriptソースコードを誤って含めて公開した。
- [事実] 漏洩コードを起点とした悪意のあるフォーク・サプライチェーン攻撃リスクが指摘されている。
- [AI分析] 本システムが `@anthropic-ai/claude-code` または関連パッケージを依存関係に含む場合、`package.json` / `package-lock.json` を精査し、公式チャネル以外からのインストールが行われていないことを確認すること。

**【中関連度】GitHub Actions サプライチェーン攻撃**

- [事実] 2026年Q1に可変アクション参照（タグ指定）を悪用したサプライチェーン攻撃が多発し、23,000以上のリポジトリが侵害された。
- [AI分析] 本プロジェクトの `.github/workflows/` 内のアクション参照を全件コミットSHAピン留めに変更することを推奨する。

**【中関連度】ローカルPC常駐運用への移行に伴うリスク**

- [AI分析] Vercel/GitHub Actions 上のクラウド完結型から「ローカルPC常駐運用」に移行することで、以下の新規リスクが発生する：
  1. APIキーがローカルの `.env` ファイルに平文保存されるリスク
  2. ローカルPCのマルウェア感染・物理的盗難によるシークレット流出リスク
  3. ローカル環境の脆弱性パッチ管理がクラウド比で劣後するリスク
  4. ネットワーク境界の不明瞭化による不正アクセスリスク

2. **[AI分析] ローカルPC常駐運用における機密情報管理の方針策定**

3. **[AI分析] Anthropic 関連 npm パッケージの依存関係監査**

### 🟡 優先度: 中（2週間以内に対応）
