## 外部脅威情報（Geminiより）

[AI分析] 以下は収集された脅威情報のうち、本システムのスタック（Python / GitHub Actions / Vercel / Next.js / Anthropic Claude API / Gemini API / 金融投資UIシステム）に直接関連するリスクを抽出・評価したものである。

### 🔴 高優先度：本システムへの直接的関連リスク

**① GitHub Actions サプライチェーン攻撃**
[事実] 2026年3月28日、Trivyを標的としたサプライチェーン攻撃により、GitHub Actionsを経由した多数のクラウド環境の認証情報が流出したことが報告されている。
[AI分析] 本プロジェクトのCI/CDがGitHub Actionsを使用している場合、使用しているサードパーティActionがSHAではなくタグ（例：`@v3`）で参照されていると、不正書き換えによる認証情報（`ANTHROPIC_API_KEY`、`GEMINI_API`等のGitHub Secrets）の流出リスクが存在する。即時対応を推奨する。

**② Vercel / Next.js の既知CVE**
[事実] CVE-2025-55182（React2Shell：RCE）、CVE-2025-55184（DoS：High severity）、CVE-2025-55183（ソースコード開示：Medium severity）がVercel/Next.js/React 19に影響することが確認されている。
[AI分析] 本プロジェクトがNext.js + Vercelデプロイ構成の場合、これら3件のCVEは直接的な脅威となる。特にCVE-2025-55182のRCEおよびCVE-2025-55184のDoSはServerless Functionの可用性・安全性に影響する。VercelのAutoパッチ適用状況を確認し、Next.jsのバージョンを最新に保つこと。

**③ Anthropic Claude Code の脆弱性（開発環境リスク）**
[事実] 2026年3月19日、Claude Code（CVE-2025-59536、CVE-2026-21852）においてRCEおよびAPIキー窃取につながる脆弱性が報告され、Anthropicはパッチをリリースしている。2026年4月3日にはCSRFトークン漏洩の脆弱性も指摘されている。
[AI分析] 開発メンバーがClaude Codeを開発環境で利用している場合、`ANTHROPIC_API_KEY`が開発PC上の環境変数として設定されており、これが悪意あるプロジェクトフック経由で窃取されるリスクがある。Claude CodeはLatestバージョンに更新し、信頼できないプロジェクトでの実行を禁止すること。

### 🟡 中優先度：間接的関連リスク

**④ 160億件認証情報流出（インフォスティーラー）**
[事実] 2025年6月20日、インフォスティーラーマルウェアによって収集された160億件の認証情報（Apple, Google, GitHub, Telegram等のサービスを含む）の流出が報告されている。
[AI分析] 開発メンバーのGitHubアカウント認証情報がこのデータベースに含まれている可能性がゼロではなく、GitHubリポジトリへの不正アクセスリスクが存在する。全開発メンバーへのパスワード変更・MFA有効化確認を推奨する。

**⑤ 金融投資UIシステムを狙ったフィッシング**
[事実] 2026年4月1日、SBI証券を騙るフィッシングメール（「損失補償手続き」等の件名）が確認されている。2025年の証券会社を狙ったリアルタイムフィッシング攻撃では約6,200億円の被害が報告されている。
[AI分析] 本システムが投資シミュレーションUIを提供している場合、エンドユーザーが類似のフィッシングUIに誘導されるリスクがある。ユーザー向けの正規URLの明示、フィッシング注意喚起バナーの設置を検討すること。

**⑥ Ciscoサプライチェーン攻撃によるAWSキー流出**
[事実] 2026年4月1日〜3日、Trivyを標的としたサプライチェーン攻撃によりCisco内部からAWSキー等のクラウド認証情報が流出した可能性が報じられている。
[AI分析] 本プロジェクトがTrivyをセキュリティスキャナとして使用している場合、侵害されたTrivyバージョンが利用されていないか確認が必要。また、AWSキーを使用している場合はローテーションを検討する。

### 🔴 緊急（本日中）

[AI分析] 以下は即時確認・対応が必要と判断する事項である。

1. **GitHub Actions SHAピニングの確認**
   [AI分析] `.github/workflows/` 配下の全workflowファイルを確認し、サードパーティActionsがSHA参照（例：`actions/checkout@a81bbbf8`形式）になっているか確認すること。タグ参照（`@v3`等）の場合は即時SHA固定化を実施する。

2. **Next.js / Vercelバージョン確認とCVE対応状況確認**
   [事実] CVE-2025-55182（RCE）、CVE-2025-55184（DoS）、CVE-2025-55183（情報漏洩）が報告されている。
   [AI分析] `package.json` のNext.jsバージョンを確認し、Vercelダッシュボードでのオートパッチ適用状況を確認すること。

3. **`c8972dd` の差異分析ログ実装のレビュー**
   [AI分析] 「差異分析ログ追加」の実装において、以下を確認すること：

   - ログデータが外部エンドポイントに送信されていないか
   - フロントエンド（クライアントサイド）にAPIキーパターンが混入していないか

## 推奨事項

[AI分析] 以下は中長期的なセキュリティ強化として推奨する施策である。

### セキュリティ設計強化

1. **ログ出力ポリシーの明文化**
   [AI分析] 今回の「差異分析ログ追加」実装を契機として、ログに出力してよい情報・してはならない情報（APIキー、ユーザー認証情報、フルAPIレスポンス等）をドキュメント化し、コードレビューチェックリストに組み込むことを推奨する。

2. **Dependabot / Renovateの導入**
   [AI分析] Next.js、Vercel関連パッケージ等の依存関係を自動監視・更新提案するDependabotまたはRenovateをGitHubリポジトリに設定し、CVE検出から修正までのリードタイムを短縮することを推奨する。

3. **GitHub Actions のOIDC認証への移行**
   [AI分析] GitHub SecretsにAWSキー等の長期認証情報を格納している場合、GitHub Actions OIDC（OpenID Connect）を利用した一時トークン発行方式に移行することで、認証情報流出時の被害を最小化することを推奨する。

4. **エンドユーザー向けフィッシング対策の実装**
   [AI分析] 本システムが金融投資UIを提供している性質上、類似サービスを騙るフィッシング詐欺（SBI証券事例等）への対策として、正規URLの証明書透明性（CT）ログ監視、ユーザーへの正規アクセス方法の明記を検討することを推奨する。

5. **Vercel Serverless Function の入力バリデーション強化**
   [AI分析] `sim-ui` のシナリオ追加（3シナリオ）に伴い、`api/claude.js` および `api/gemini.js` へのリクエストパラメータが増加している可能性がある。想定外のパラメータによるプロンプトインジェクションや過大リクエストによるDoS（CVE-2025-55184と類似のリスク）に対して、Serverless Function側でのスキーマバリデーションを強化することを推奨する。
