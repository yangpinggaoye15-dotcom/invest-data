## 要対応事項

### ⚡ 緊急（直ちに確認）

```
1. [axios サプライチェーン攻撃]
   package.json / package-lock.json の axios バージョンを確認し、
   侵害されたバージョン（2026-03-31前後のリリース）が混入していないか検証する。
   対応: npm audit を実行し、クリーンなバージョンへの固定（pin）を行う。

2. [Next.js バージョン確認]
   CVE-2025-55182（RCE）/ CVE-2026-27977・27978（CSRF）への対応として、
   Next.js のバージョンが 15.5.13 または 16.1.7 以上であることを確認する。
   対応: package.json の next バージョンを確認し、未満であれば即時アップデート。
```

### 📋 今週中に対応

```
3. [コミット208261dの内容精査]
   「全36名の個人マニュアル作成」の具体的なファイル内容を確認。
   個人情報（氏名・メールアドレス・認証情報等）がリポジトリに
   コミットされていないかを diff レベルで検査する。
   → Public / Private リポジトリ設定も合わせて確認すること。

4. [Claude Code 利用者の確認]

   CVE-2026-21852 の影響を受ける可能性があるため、

```

### 📅 今月中に対応

6. [Python バージョン・ライブラリ更新]

## 推奨事項

### セキュリティ強化施策

```
【1. 依存関係の自動監視強化】
GitHub Dependabot または Renovate Bot を有効化し、
axios・next.js 等の重要パッケージの脆弱性を自動検知する体制を整える。
また、npm audit を GitHub Actions の CI パイプラインに組み込む。

【2. APIキーの定期ローテーション】
ANTHROPIC_API_KEY / GEMINI_API_KEY について、
四半期に1回以上のキーローテーションポリシーを策定・実施する。
Vercel環境変数の確認もあわせて行う。

【3. シークレットスキャンの導入】
GitHub Secret Scanning（無料機能）を有効化し、
万が一のコミットへのAPIキー混入を即時検知できる仕組みを整える。
ローカル開発環境では git-secrets または gitleaks の導入を推奨。

【4. 利用者（36名）へのセキュリティ啓発】
SNS型投資詐欺・フィッシング・ディープフェイク詐欺が過去最悪規模で
発生していることを踏まえ、個人マニュアルにセキュリティ注意事項
（不審なURLへのアクセス禁止・認証情報の共有禁止等）を明記する。

【5. Vercel WAF設定の確認】
CVE-2025-55182対応としてVercelがWAFルールを展開済みだが、
カスタムWAFルールや不審なリクエストのアラート設定が
有効になっているかVercelダッシュボードで確認する。

【6. インシデントレスポンス手順の整備】
APIキー漏洩発生時の対応フロー（検知→無効化→ローテーション→報告）
をドキュメント化し、チーム全員が即時対応できる体制を構築する。
```
